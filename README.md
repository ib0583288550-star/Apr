# ניהול משתמשים Root

אפליקציית Android 13 עם ממשק עברי לניהול Multiple Users במכשירים שבהם היצרן הסתיר את ממשק המשתמשים.

## מה האפליקציה עושה
- זיהוי גישת Root.
- הצגת המשתמשים הקיימים.
- הצגת מספר המשתמשים המרבי שהמערכת מדווחת עליו.
- יצירת משתמש.
- מעבר למשתמש.
- מחיקת משתמש שאינו הבעלים.
- רענון הרשימה.

האפליקציה משתמשת בפקודות מערכת דרך Root ואינה משנה קבצי מערכת.

## בנייה
GitHub Actions בונה Debug APK ומעלה אותו כ-artifact בשם `app-debug`.
