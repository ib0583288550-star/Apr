# כפתורי טרמינל

אפליקציית Android ב-Kotlin + Jetpack Compose + Material 3.

## מה האפליקציה עושה
- מוסיפים כמה כפתורים שרוצים.
- לכל כפתור נותנים שם ופקודת Shell.
- לחיצה על הכפתור מריצה את הפקודה במעטפת המקומית של Android ומציגה את הפלט.
- הכפתורים נשמרים גם אחרי סגירת האפליקציה.
- אפשר למחוק כפתורים.

## פקודות זמינות כרגע
מטעמי בטיחות, הגרסה הזו מאפשרת רק פקודות מידע/פלט:
`echo`, `pwd`, `ls`, `date`, `whoami`, `id`, `uname`, `getprop`.

## בנייה
כל push ל-main מפעיל GitHub Actions. בסיום אפשר להוריד את `app-debug` מתוך Artifacts.
